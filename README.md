# Steam Game Favorite

การบ้านสัปดาห์ที่ 2: แอป Flutter บันทึกเกมโปรด โทน iOS เก็บข้อมูลถาวรด้วย SQLite ผ่าน sqflite

## ฟีเจอร์

- อ่านรายการจาก SQLite ด้วย `ListView.builder`, `Card` และ `ListTile`
- เพิ่มและแก้ไขเกมผ่านฟอร์ม ตรวจชื่อและรายละเอียดห้ามว่าง
- ลบเกมโดยแสดงกล่องยืนยันก่อนลบ
- แตะรายการเพื่อเปิดหน้ารายละเอียดด้วย `Navigator.push` และ `MaterialPageRoute`
- แสดงรูปเกมจาก Steam พร้อมไอคอนสำรองเมื่อโหลดรูปไม่ได้
- แสดงอารมณ์และคะแนนดาวของแต่ละเกม
- กรองรายการตามอารมณ์
- Challenge Lab 2: นับจำนวนเกมทั้งหมดบน AppBar อัปเดตหลังเพิ่ม/ลบ
- Challenge เสริม: ค้นหาชื่อเกมด้วย List.where ร่วมกับตัวกรองอารมณ์
- มีหน้า About พร้อมชื่อและรหัสนักศึกษา
- เริ่มด้วย empty state และปุ่มเพิ่มเกม
- คะแนน Slider, อารมณ์ Dropdown และวันที่ DatePicker บันทึกลง SQLite

## โครงสร้าง

- `lib/main.dart`: หน้ารายการ รายละเอียด About และ setState
- `lib/models/steam_game.dart`: Model และ toMap/fromMap
- `lib/data/database_helper.dart`: CREATE TABLE และ CRUD
- `lib/pages/game_editor_page.dart`: ฟอร์มเพิ่มและแก้ไข

ข้อมูลข้อความอยู่ในเครื่อง รูป URL ต้องใช้อินเทอร์เน็ต มีไอคอนสำรองเมื่อไม่มีรูป ไม่เรียก Steam API คะแนนดาวเป็นคะแนนที่ผู้ใช้กำหนดเอง

## ตรวจงานและคลิปไม่เกิน 90 วินาที

1. 0–10 วินาที: แสดง empty state และกดบันทึกฟอร์มว่างให้เห็น validator
2. 10–30 วินาที: เพิ่มชื่อเกม รายละเอียด เลือกคะแนน อารมณ์ วันที่ แล้วบันทึก
3. 30–45 วินาที: แตะเกม กดแก้ไข แสดงค่าเดิม แก้ข้อมูลและบันทึก
4. 45–65 วินาที: ปัดแอปออกจากตัวสลับแอป เปิดจากไอคอนใหม่ แสดงข้อมูลเดิม
5. 65–80 วินาที: กดลบ ยืนยัน และแสดง empty state อีกครั้ง

## Lab สัปดาห์ที่ 2 (ต่อยอดแอปเดิม)

ใบงาน: https://thipwimon.comsciproject.net/week2-lab.html

ใช้แอป Steam Game Favorite เดิม ไม่ใช่โปรเจกต์ใหม่ และใช้ฐานข้อมูล

- Lab 1: mood มีครบใน Model, CREATE TABLE, toMap/fromMap และฟอร์ม

- Lab 3: แตะเกม → ปุ่มลบ → ยกเลิกหรือยืนยันก่อนลบจริง
