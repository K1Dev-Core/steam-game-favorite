# Steam Favorite

Steam Favorite เป็นแอปสำหรับค้นหาและเก็บรายชื่อเกม Steam ที่ชอบไว้ในบัญชีของตัวเอง ดูรายละเอียดเกมและคะแนนได้ในที่เดียว
## ฟีเจอร์

- สมัครสมาชิกและเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน
- ค้นพบเกม Steam พร้อมรูปปกและรายละเอียด แล้วเพิ่มเกมที่สนใจไปยังรายการโปรด
- ดูรายละเอียดเกม คะแนน และข้อมูลประกอบ
- เพิ่ม แก้ไข และลบเกมในรายการส่วนตัว
- เก็บข้อมูลสำรองไว้ใน SQLite บนอุปกรณ์ และซิงก์รายการของบัญชีผ่าน Firestore
- ใช้ REST API สำหรับอ่าน เพิ่ม แก้ไข และลบรายการ โดยตรวจสิทธิ์ด้วย Firebase ID token
- เลือกหมวดหมู่เกม ให้คะแนน และกรองเฉพาะเกมที่กดถูกใจ
- เลือกรูปปกจากคลังภาพหรือถ่ายรูปใหม่ แล้วบันทึกไว้กับเกม
- เปิดดูความคิดเห็นของชุมชนเกี่ยวกับเกม
- ข้อมูลเกมส่วนตัวแยกตามบัญชีและซิงก์ผ่าน Cloud Firestore

การเข้าสู่ระบบและการซิงก์ข้อมูลต้องเชื่อมต่ออินเทอร์เน็ต รายการที่เคยโหลดไว้ยังเปิดดูจากฐานข้อมูล SQLite ในเครื่องได้

## วิธีติดตั้งบน Android

1. ดาวน์โหลดไฟล์ `app-release.apk` และเปิดไฟล์บนโทรศัพท์ Android
2. หากโทรศัพท์ถาม ให้แตะอนุญาตติดตั้งแอปจากแหล่งที่ใช้เปิดไฟล์
3. ติดตั้งเสร็จแล้ว เปิด **Steam Favorite** จากไอคอนบนหน้าจอ
4. สมัครบัญชีใหม่ หรือเข้าสู่ระบบด้วยบัญชีที่มีอยู่
5. ค้นหาเกมที่ชอบแล้วเพิ่มลงในรายการโปรด

แอปรองรับ Android 7.0 (API 24) ขึ้นไป สำหรับผู้พัฒนาที่ต้องการสร้าง APK เอง ใช้คำสั่ง:

```bash
flutter pub get
flutter build apk --release
```

ไฟล์ APK จะอยู่ที่ `build/app/outputs/flutter-apk/app-release.apk` ส่วนไอคอนต้นฉบับอยู่ที่ `assets/icon.png` และ `assets/icon.svg`

## การจัดเก็บข้อมูล

แอปใช้ Firebase Authentication สำหรับบัญชีผู้ใช้ และ Cloud Firestore สำหรับรายการเกม แต่ละรายการผูกกับเจ้าของบัญชี และ Firestore Security Rules จำกัดการอ่านหรือแก้ไขไว้เฉพาะเจ้าของข้อมูล การค้นพบเกมและความคิดเห็นชุมชนโหลดจาก API ของโปรเจกต์
