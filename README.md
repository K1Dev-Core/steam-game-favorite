# Steam Game Favorite

แอป Flutter สำหรับบันทึกเกม Steam ที่ชอบ ออกแบบโทน iOS และใช้ข้อมูลเกมแบบ local ในตัวแปร

## ฟีเจอร์

- แสดงเกมโปรด 7 รายการด้วย `ListView.builder`, `Card` และ `ListTile`
- แตะรายการเพื่อเปิดหน้ารายละเอียดด้วย `Navigator.push` และ `MaterialPageRoute`
- แสดงรูปเกมจาก Steam พร้อมไอคอนสำรองเมื่อโหลดรูปไม่ได้
- แสดงอารมณ์และคะแนนดาวของแต่ละเกม
- กรองรายการตามอารมณ์
- มีหน้า About พร้อมชื่อและรหัสนักศึกษา
- ปุ่มเพิ่มเกมแสดงแจ้งเตือน เนื่องจากฟีเจอร์ยังไม่เปิดใช้งาน

## Run

```bash
flutter pub get
flutter run
```
